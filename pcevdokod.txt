2. Псевдокод программы

Начало программы
Настроить кодировку консоли на русский язык

Цикл (пока пользователь не выбрал выход):
    Очистить экран
    Отобразить главное меню:
        1 - Начать анализ текста на рифмы причастий
        2 - Инструкция пользователя
        0 - Выход из программы
    
    Получить проверенный ввод пункта меню (0, 1 или 2)

    Если выбор = 0:
        Прервать цикл и завершить работу

    Если выбор = 2:
        Считать и вывести на экран содержимое файла "instructions.txt"
        Ожидать нажатия клавиши Enter для возврата

    Если выбор = 1:
        // ШАГ 1: ВЫБОР И ПРОВЕРКА ВХОДНОГО ФАЙЛА (UI)
        Отобразить список предустановленных файлов:
            1 - test_poem.txt (Стих с причастиями и деепричастием-ловушкой)
            2 - test_mayakovsky.txt (Лесенка Маяковского, много пробелов)
            3 - test_prose.txt (Проза без рифм)
            4 - test_empty.txt (Пустой файл)
            5 - Ввести путь к файлу вручную
            0 - Назад в главное меню
        
        Получить выбор пользователя (0..5)
        Если выбор = 0:
            Вернуться в главное меню
            
        Если выбран ручной ввод (5):
            Запросить имя файла
            Если имя содержит запрещенные символы Windows (< > : " / \ | ? *):
                Вывести ошибку, вернуться к выбору файла
        
        Проверить физическое наличие и доступность файла на диске
        Если файл не открывается или пуст:
            Вывести сообщение об ошибке, вернуться к выбору файла

        // ШАГ 2: НАСТРОЙКА ПАРАМЕТРОВ ПОИСКА (UI)
        Запросить у пользователя размер окна поиска рифм:
            (0 - искать во всем тексте, N > 0 - максимальное расстояние в предложениях)
            (или ввод -1 для возврата назад)
        Если введен отказ (-1):
            Вернуться в главное меню

        // ШАГ 3: ЧТЕНИЕ ТЕКСТА И ВЫДЕЛЕНИЕ ПРИЧАСТИЙ (Никита: TextParser + ParticipleDetector)
        Вывести в консоль: "Чтение файла и поиск причастий: "
        Инициализировать счетчик предложений = 1
        Инициализировать список ParticiplesList = []
        Инициализировать счетчик слов = 0

        Пока из входного файла извлекаются слова:
            Очистить слово от знаков препинания и привести к нижнему регистру
            Увеличить счетчик слов на 1
            Если (счетчик слов mod 500 == 0):
                Вывести "." в консоль (индикация процесса)
            
            Если встречен знак конца предложения ('.', '!', '?'):
                Увеличить счетчик предложений на 1
            
            Если Слово_Является_Причастием(слово):
                Добавить пару (слово, счетчик предложений) в ParticiplesList
        
        Закрыть входной файл
        Вывести: "\nНайдено причастий: " + размер(ParticiplesList)
        
        Если ParticiplesList пуст:
            Вывести: "Причастия в тексте не обнаружены."
            Ожидать нажатия Enter, вернуться в главное меню

        // ШАГ 4: ПОИСК РИФМУЮЩИХСЯ ПАР (Мария: RhymeDetector)
        Вывести в консоль: "Сопоставление рифмующихся пар: "
        Инициализировать список RhymePairs = []

        Для каждого элемента i от 0 до размера(ParticiplesList) - 1:
            Для каждого элемента j от i + 1 до размера(ParticiplesList):
                Если окно поиска > 0 И разница предложений (предл[j] - предл[i]) > окно поиска:
                    Пропустить проверку (выход за пределы окна)
                
                Если Слова_Рифмуются(слово[i], слово[j]):
                    Добавить в RhymePairs пару со сведениями о словах и их предложениях
            
            Если (i mod 100 == 0):
                Вывести "." в консоль (индикация процесса)
        
        Вывести: "\nВсего найдено рифмующихся пар: " + размер(RhymePairs)
        
        Если RhymePairs пуст:
            Вывести: "Рифмующихся пар не найдено."
            Ожидать нажатия Enter, вернуться в главное меню

        // ШАГ 5: СБОР СТАТИСТИКИ И СОРТИРОВКА (Мария: RhymeDetector)
        Инициализировать массив WordStats = []
        Для каждого уникального слова из RhymePairs:
            Посчитать, сколько раз слово участвует в парах (частота)
            Собрать список уникальных номеров предложений, где оно встретилось
            Добавить объект WordStat(слово, частота, список предложений) в WordStats

        Выполнить сортировку массива WordStats методом прямого выбора (Selection Sort):
            По убыванию частоты вхождений в рифмы (при равенстве — по алфавиту)

        // ШАГ 6: СОХРАНЕНИЕ РЕЗУЛЬТАТОВ В ФАЙЛ (UI)
        Вывести в консоль краткие итоги работы
        Сформировать шаблонное имя выходного файла: <ВходнойФайл>_Рифмы.txt
        
        Если файл с таким именем уже существует:
            Сформировать безопасное имя с индексом: <ВходнойФайл>_Рифмы(1).txt
            Спросить пользователя:
                "Файл существует. Перезаписать? (введите Y) или сохранить как " + БезопасноеИмя + " (любая клавиша): "
            Если ввод != 'Y':
                Имя выходного файла = БезопасноеИмя

        Открыть выходной файл на запись
        Записать заголовок отчета, параметры поиска (окно) и общее число пар
        Для каждого элемента из отсортированного списка WordStats:
            Записать слово
            Записать количество вхождений в пары
            Записать номера предложений через запятую
        Закрыть выходной файл

        Вывести: "Результаты успешно сохранены в файл: " + ИмяВыходногоФайла
        Ожидать нажатия клавиши Enter для возврата в главное меню
